# ADR-003：Chat 领域边界与停用状态

- 状态：已接受
- 日期：2026-09-11

## 背景

现有 chat 包含 WebSocket、HTTP 路由、存储与运行时依赖，但实时通讯不属于当前演进主线。继续注册会扩大迁移面并混淆 Web 文档系统与未来 QQ Agent 的边界。

## 决策

1. 保留 chat 源码、迁移与测试资产，取消服务初始化、路由注册、导航入口和 readiness 依赖。
2. /api/chat、/api/chatws 及其子路径在当前运行时统一返回 404；不提供兼容代理。
3. Web 文档协作与 QQ Agent 是两个独立上下文，不共享会话表、长连接或领域模型。
4. 阶段 1 允许破坏性拆除 chat 与 PostgreSQL 连接初始化的耦合，但不删除 chat 代码。
5. 重新接入必须单独提交 ADR，明确身份映射、可靠投递、容量与运维责任。

## 结果

- 实时通讯保持“代码中存在，但不接入”。
- 当前部署不再因 chat 资源影响启动或 readiness。
- 将来恢复功能需要显式架构决策，不会被无意注册。

## 验证

gin-backend 的路由回归测试覆盖 /api/chat、/api/chatws 及 WebSocket 升级请求均返回 404。
