# ADR-002：文档事实与索引所有权

- 状态：已接受
- 日期：2026-09-11

## 背景

文档正文、权限和生命周期目前由 go-web 管理。mixin-search 保存向量、稀疏索引和检索元数据。如果两侧都成为事实源，删除、权限撤销与版本切换会出现不可审计的分叉。

## 决策

1. go-web 是文档、空间成员关系、权限、生命周期和发布状态的唯一事实源。
2. mixin-search 只拥有可重建的派生索引，不反向修改业务文档。
3. 每次索引操作携带 document_id、revision、lifecycle_revision、access_revision 与 idempotency_key。
4. 新 revision 完整写入并校验成功后才能激活；失败时旧 active revision 继续服务。
5. 删除与权限撤销采用至少一次投递和幂等消费，消费者必须拒绝过期 lifecycle_revision 或 access_revision。
6. 阶段 1 用事务 Outbox 固化事实变更；阶段 2 才启动影子索引消费者。

## 结果

- 索引可以删除并重建，业务事实不会丢失。
- 乱序重试不会复活已删除文档或恢复旧权限。
- 所有权边界会增加事件版本字段和修复任务，但换取可审计的一致性。

## 验证

阶段 1 的契约测试必须覆盖重复事件、乱序事件、失败重试、删除后迟到更新和权限撤销后迟到授权。
